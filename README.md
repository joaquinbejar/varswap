# VarSwap

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)

Realized variance and variance swaps on Solana.

A program accumulates realized variance from Pyth prices over a fixed window, guarding against stale or low-confidence updates, and settles variance swaps against a variance strike.

**Status:** design phase, no code yet.
